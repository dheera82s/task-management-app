
# Task Management Application

## Project Overview
A real-world DevOps project to deploy a Task Management Application using modern DevOps tools.

## Technologies Used
- Git
- GitHub
- Docker
- Docker Hub
- Kubernetes
- Terraform
- GitHub Actions
- AWS

## Application Architecture
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL

## DevOps Implementation

1. Source Code Management using Git and GitHub
2. Docker Containerization
3. Docker Image Management using Docker Hub
4. Application Deployment using Kubernetes
5. AWS Infrastructure Provisioning using Terraform
6. CI/CD Automation using GitHub Actions

## Project Goal
To automate application build, deployment and infrastructure management using DevOps practices.
